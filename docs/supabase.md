# Supabase integration

The Supabase MCP configuration is project-scoped and read-only while the schema is audited. Authenticate through the browser when Codex prompts; no secrets are stored in the repository. The initial RSVP schema is documented in `docs/schema.md` and versioned in `supabase/migrations/`. Public client credentials may be used only for browser-safe configuration; never expose service-role credentials.
